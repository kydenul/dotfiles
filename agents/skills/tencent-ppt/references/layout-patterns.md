# Layout Patterns - HTML/CSS Implementation

This reference provides HTML/CSS patterns for every slide layout type in the Tencent PPT Template system.

## Architecture Overview

Each presentation project has three files:

| File | Generated by LLM? | Description |
|------|-------------------|-------------|
| `index.html` | ✅ Yes | All slides as `<div class="slide">` elements + `<link>` to CSS + `<script>` to app.js |
| `styles.css` | ✅ Yes | All slide styles — shared classes + per-slide `[data-slide="N"]` scoped rules |
| `assets/` | ❌ No (hard-linked) | Static: `js/app.js` (slideshow engine), `fonts/`, `media/` |

**`app.js` is a static skill asset** — it handles viewport scaling, keyboard navigation, fullscreen, progress bar, and PDF export. The LLM never modifies it.

## Project Structure

```
slides-output/
├── index.html          # LLM-generated: slide HTML content
├── styles.css          # LLM-generated: all CSS rules
└── assets/             # Hard-linked from skill assets (ln)
    ├── js/app.js       # Slideshow engine (static, never modified)
    ├── fonts/
    │   ├── TencentSans-W3.ttf
    │   └── TencentSans-W7.ttf
    └── media/
        ├── pattern-*.png
        ├── ending-pattern-*.png
        ├── section-block-bg.png
        ├── footer-bar.png
        ├── tencent-logo-*.png
        └── ...
```

## index.html Template

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Presentation Title</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <div class="slide-viewport">

    <!-- Slide 1: Cover -->
    <div class="slide cover active" data-slide="1">
      <div class="cover-pattern">
        <img src="assets/media/pattern-grid.png" alt="" class="pattern-img">
      </div>
      <div class="cover-content">
        <img src="assets/media/tencent-logo-white.png" alt="Tencent" class="cover-logo">
        <h1 class="cover-title">Presentation Title</h1>
        <p class="cover-subtitle">Subtitle or date</p>
      </div>
    </div>

    <!-- Slide 2: TOC -->
    <div class="slide toc-slide" data-slide="2">
      <!-- ... -->
    </div>

    <!-- ... more slides ... -->

  </div>

  <script src="assets/js/app.js"></script>
</body>
</html>
```

**Rules:**
- Every `<div class="slide">` must have a `data-slide="N"` attribute (1-indexed, sequential)
- Exactly ONE slide has the `active` class (typically `data-slide="1"`)
- The `<script src="assets/js/app.js">` must be the last element before `</body>`
- The `<link rel="stylesheet" href="styles.css">` goes in `<head>`
- No inline `<style>` blocks — all CSS goes in `styles.css`
- No inline `<script>` blocks — all JS is in `app.js`

## styles.css Template

```css
/* ============================================
   FONTS
   ============================================ */
@font-face {
  font-family: 'TencentSans';
  src: url('assets/fonts/TencentSans-W3.ttf') format('truetype');
  font-weight: 300;
}
@font-face {
  font-family: 'TencentSans';
  src: url('assets/fonts/TencentSans-W7.ttf') format('truetype');
  font-weight: 700;
}

/* ============================================
   GLOBAL RESET & VIEWPORT
   ============================================ */
* { margin: 0; padding: 0; box-sizing: border-box; }

html, body {
  width: 100%; height: 100%;
  overflow: hidden;
  background: #1a1a2e;
  margin: 0;
}

.slide-viewport {
  width: 100vw; height: 100vh;
  position: relative;
  background: #1a1a2e;
  overflow: hidden;
}

.slide {
  width: 1920px; height: 1080px;
  position: absolute; overflow: hidden;
  font-family: 'TencentSans', 'Microsoft YaHei', 'PingFang SC', sans-serif;
  transform-origin: 0 0;
  display: none;
  background: #FFFFFF;
}
.slide.active { display: block; }

/* ============================================
   SHARED CONTENT SLIDE STYLES
   ============================================ */
.slide-header {
  position: absolute; left: 59px; top: 48px;
  display: flex; align-items: center; gap: 12px;
}
.badge {
  width: 48px; height: 48px; border-radius: 50%;
  background: #0052D9;
  display: flex; align-items: center; justify-content: center;
}
.badge span { color: #FFFFFF; font-size: 24px; font-weight: 700; }
.section-label { font-size: 26px; font-weight: 700; color: #0052D9; }

.content-heading {
  position: absolute; left: 98px; top: 110px;
  font-size: 48px; font-weight: 700; color: #0052D9;
}

.slide-footer {
  position: absolute; bottom: 0; left: 0; right: 0;
  height: 50px; z-index: 1;
}
.footer-bar {
  position: absolute; bottom: 0; left: 0;
  width: 100%; height: 45px; object-fit: cover;
}
.page-number {
  position: absolute; bottom: 18px; left: 17px;
  font-size: 14px; font-weight: 300; color: #BFBFBF;
}

/* ============================================
   PER-SLIDE STYLES (use [data-slide="N"] scoping)
   ============================================ */

/* Example:
[data-slide="1"] { background: linear-gradient(135deg, #0a0a2e 0%, #0d1b3e 30%, #0052D9 100%); }
[data-slide="3"] .custom-element { color: #FF7535; }
*/
```

**CSS rules:**
- `@font-face` declarations go first
- Global reset and `.slide-viewport` / `.slide` base styles go next
- Shared content-slide classes (`.slide-header`, `.badge`, `.content-heading`, `.slide-footer`, etc.) follow
- Per-slide styles use `[data-slide="N"]` selectors for scoping
- **Never** set `font-family` on any element other than `.slide` — all children inherit

## Media Embedding

- **Local files**: Hard-link into `assets/media/`, then use relative path: `<img src="assets/media/photo.jpg">`
- **Remote URLs**: `<img src="https://example.com/img.jpg">`
- **Video**: `<video controls autoplay muted loop playsinline><source src="assets/media/demo.mp4" type="video/mp4"></video>`
- **Animated GIF**: Standard `<img>` tag — auto-plays
