# 分层 AGENTS.md 维护守则

- **分层下钻**：仓库根为 L0（入口：架构、技术栈、目录速查、启动方式、常见入口），子目录为 L2/L3；上层只放一句话摘要 + 链接。
- **DRY**：每个事实只写在最贴近代码的那一层。
- **Size**：L0 ≤ 10KB，L2 ≤ 50KB；超出说明该层职责过大，应再下钻。
- **不复制代码细节**：字段、函数签名直接读源码（源码应有注释）；文档只讲「为什么 / 怎么协作 / 去哪改」。
- 「常见入口」表按「想做什么 → 改哪里」组织。
- 改动代码导致文档失真时，同一次改动里同步更新对应层的 AGENTS.md。
